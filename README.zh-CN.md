# PointToFix Craft — 屏幕标注工具(Rust 重写版)

> English README: [README.md](README.md)

以经典屏幕标注软件 [Pointofix](https://www.pointofix.de/)(Delphi 编写,1.8.0)为逆向分析目标,
用 **Rust + eframe/egui + windows-rs** 从零重写的练手项目(REA:Reverse Engineer Everything)。

> 只复刻行为,不提取原版代码/资源 —— 功能不受版权保护,实现和素材全部原创。

## 当前能力(v0.2)

- 待机:右上角浅色小面板(顶部拖动条可移动,位置自动记忆;× 退出),点「开始标注」进入标注模式;
  待机面板位置按**物理像素**记录(`standby_px`),挪到不同缩放的显示器上也不会漂
- **多显示器(单屏标注)**:点「开始标注」时,**按钮在哪块屏,就只标注哪块屏**——
  覆盖层窗口精确等于那块显示器的物理矩形,其他屏幕完全不碰(不铺、不截、不挡);
  在别的屏上画/点都不会有反应;**存图/复制/打印也只出这一块屏的画面**;
  每个标注会话按该屏自己的 DPI 渲染,所以笔宽、工具条大小都适合当前屏幕;
  显示器改分辨率/改缩放会自动重新贴合,拔掉则退回主屏;退出标注回到进入前的位置
- 工具条顶部有拖动圆点,可拖到屏幕任意位置,**位置跨启动记忆**;默认放当前屏右上角,
  **不会跨屏**:整条工具条(含高度)被限制在这块屏内,屏幕太矮装不下时**按比例缩小**;
  拖到屏幕外/换到更小的屏也会自动调整回可见位置
- 工具条完全对齐原版布局:单列窄条、图标按钮(矢量绘制,悬停有当前语言提示):
  完成 → 笔宽 4 档圆点 → **双色卡(左列不透明 / 右列透明=马克笔,对所有工具生效)** →
  画笔/橡皮擦 → 直线/箭头 → 框/实框 → 圆/实圆 → 双箭头/文字 →
  ✓打勾 / ✗打叉盖章 → 框选区域/**选区去背** → 放大镜+/− → ↩撤销/🗑清空 →
  打印/保存 → 复制/**设置**
- **设置与多语言**(Ctrl+I):原「关于」按钮改为齿轮「设置」,窗口内含**语言选择
  (中文 / English / Deutsch / 日本語)+ 截图保存格式与清晰度 + 选区去背方式与 ISNet 模型状态 +
  关于信息 + 调试模式开关**;切换即时生效,
  语言与存图设置写入 `%APPDATA%\pointtofix\ui.txt`(`lang=zh|en|de|ja`、`format=webp|png`、
  `quality=1..100`、`lossless=1`),首次启动跟随系统 UI 语言;
  工具条提示、待机面板、设置窗口、提示消息与截屏/打印错误全部走同一套 i18n(`src/i18n.rs`)
- **存图格式与清晰度**(设置面板「截图保存」):默认 **WebP**(libwebp 编码),
  格式可切 PNG;WebP 有损压缩的**清晰度 1–100 可调**,或勾选**无损压缩**做到与原始画面完全一致;
  勾选无损 / 切到 PNG 时清晰度滑块自动置灰(此时画质不变,调它无意义);
  存图提示会带上实际文件大小,方便确认优化效果
  > 实测(2560×1600 整屏真实桌面):PNG 2.50 MB → **WebP 清晰度 85 = 255 KB(约 1/10)**;
  > WebP 无损 1.22 MB(仍比 PNG 小 2.2×);清晰度 30 = 104 KB
  > 代价:编码和原来的 PNG 路径一样在 UI 线程同步执行,dev 构建整屏编码 PNG 约 0.16 s、
  > WebP q85 约 0.4 s、WebP 无损约 2 s(release 构建快得多);选区存图只编码选区像素,基本无感
- 笔宽 2/4/8/12 px 四档,同时也是盖章大小(18~108px)与橡皮大小
- **橡皮擦(圆形笔刷)**:只擦掉圆圈内的那部分墨迹——笔画/直线/箭头/矩形/椭圆按圆切断,
  实心图形抠出圆形缺口(扫描线近似),箭头被圈住时只去掉头部;**不再整笔删除**;
  圆形光标跟随鼠标标出实际擦除范围(应用内存图/复制时自动隐藏,普通屏幕截图可见);
  文字/勾叉这类不可切分的标记仍是碰到即移除
- **Shift 约束**:直线/箭头吸附 45°,矩形→正方形,椭圆→正圆
- **勾/叉盖章**:选中 ✓ 或 ✗ 后在画布上点击盖章,大小跟随笔宽档位
- **框选区域**(Ctrl+R):拖拽只选定区域(虚线框保留并标注尺寸),**不立即截图**;
  「存图」「复制」「打印」只作用于选区(有选区时),无选区时作用于整屏(= 当前这块显示器);Esc 清除选区;
  **选区自动保存到 %APPDATA%\pointtofix\region.txt,下次开始标注时恢复显示**;
  **选框存在时,墨迹被裁剪到选框内——勾、箭头等超出选框的部分不显示**(与导出画面一致)
- **+/− 放大/缩小选框区域**:×1 → ×2 → ×4 → ×8 → ×10 逐级,冻结当前画面、以框中心锚定放大
- **选区去背(背景变白)**:⊠ 按钮或 Ctrl+D 一键把选框内的背景变白
  (再按一次还原)——**标注在独立矢量图层,去背时完全不参与抓图,所以箭头/勾叉等标注绝不会被去掉**;
  白底结果垫在墨迹下方,可继续在白底上标注;「存图/复制/打印」直接使用处理后的画面
  (按用户要求,原版的多级"新页面"背景菜单未实现)
  - **两种引擎,设置里可切**:
    - **键控**(默认回退):**背景 = 从选框边框能连通过的色块**,而不是全图颜色匹配——
      物体侧面/孔壁即使和背景色很接近(差几个色阶)也会保留;未与边框连通、颜色落在背景容差内的
      连通块按**整块平均色距**判定:只有平均色距 ≤3 的封闭背景(表格格子/孔底)才去掉,
      孔壁高光/零件侧面这类只有部分像素接近背景的块整块保留。这样 CAD 零件的侧面、
      孔壁、下方台阶都能保留原色,外部渐变背景照样变白;
    - **ISNet ONNX 模型**:模型 + `onnxruntime.dll` 放到程序目录、`models\` 子目录或
      `%APPDATA%\pointtofix\models` 即可启用(也可用环境变量 `POINTTOFIX_ISNET_MODEL` /
      `POINTTOFIX_ORT_DLL` 指定),支持这几个版本:
      | 模型 | 体积 | 实测(本机 1024×1024) | 说明 |
      | --- | --- | --- | --- |
      | `isnet-general-use-fp16.onnx` | **88 MB** | **≈2.5 s** | **推荐**:画质≈fp32,体积减半,速度还略快 |
      | `isnet-general-use.onnx` | 176 MB | ≈2.6 s | rembg 官方 fp32 原版 |
      | `isnet-general-use-int8.onnx` | **44 MB** | ≈2.8 s | int8 量化,最小;CPU 上反而略慢(反量化开销) |
      文件名以 `isnet` 开头、`.onnx` 结尾都会被扫描到;`isnet-general-uxe.onnx`(用户命名)也兼容。
      模型从魔搭社区下载(国内直连):
      [onnx-community/ISNet-ONNX](https://www.modelscope.cn/models/onnx-community/ISNet-ONNX)(fp16 / fp32 / int8)
      或 `dragonsoar/imging-background-removal`(imgly 的 CPU 量化版)。
      一键准备(模型 + DLL 都放到 `models\`):
      ```bash
      python scripts/fetch_isnet.py                # 默认 fp16 (88 MB)
      python scripts/fetch_isnet.py --variant int8 # 最小 (44 MB)
      ```
      **自动**模式下先跑一次键控:只要键控能稳定找到背景(默认背景占比 ≥15%,
      截图、图表、CAD、表格都满足)就直接用键控——**细线、网格线、文字都不会被 AI 当背景抹掉**;
      只有键控几乎找不到背景(复杂照片)才交给 ISNet;模型缺失/推理失败时自动回退键控。
      **浅色前景转黑**(默认开,设置可关):键控去背后,深色主题上的浅灰文字会被反相压暗
      (保留色相),白底上仍然清晰;**只压暗面积小于全图 2% 的孤立浅色组件**,
      大块浅色物体(浅色零件面、白色面板)保持原色;只作用于键控结果,ISNet 照片模式不受影响。
      键控取背景时会跳过最外 2px(截图白边/选框描边不再干扰取键)。
      **Matting 关闭**:只使用模型前景遮罩 + 软阈值,不做 alpha matting / trimap。
  - 推理走 **ONNX Runtime**(`onnxruntime.dll`,运行期动态加载):本机实测 fp16 模型
    1024×1024 约 **2.5 s**;换纯 Rust 解释器(tract)同模型要 20 s,所以不用。
    模型加载/推理都在**后台线程**执行,选区中央显示"正在去背 + 已等待秒数",界面不卡死
  > 性能:键控去背与选区截图均**只处理选区像素**(不做整屏运算),dev 构建也开启了 opt-level=1
- **截图包含墨迹**:存图/复制/打印通过"桌面底图 + egui 帧缓冲合成"生成,覆盖层(墨迹/去背白底)
  一定会被截进去;普通模式自动隐藏工具条/选框边框等界面元素,**设置面板勾选「调试模式」后
  导出整屏并连工具条一起截进去**,方便发图反馈问题(设置持久化)
- **放大镜**(Ctrl+M:跟随鼠标实时放大,滚轮调倍率 1.5×~8×)
- 存图(桌面生成 `pointtofix_<时间戳>.webp`,设置里可切 PNG)、复制到剪贴板(含墨迹的当前屏幕)、打印(默认打印机,等比适配页面居中)
  > 剪贴板与打印仍走原始 RGBA(位图不经有损压缩),只有落盘文件按上面的格式与清晰度编码
- Esc 分级取消:正在框选 → 已有选区 → 文字编辑 → 放大镜 → 退出标注;退出时清空画布

## 热键说明

| 按键 | 作用 |
| --- | --- |
| Esc | 分级取消/退出标注 |
| Ctrl+R | 框选区域(只选,不截) |
| Ctrl+S | 保存(有选区只存选区,否则整屏) |
| Ctrl+C | 复制到剪贴板(同上,可选区) |
| Ctrl+D | 选区去背(背景变白)开关 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+M | 跟随放大镜开关 |
| Ctrl+I | 设置(语言 / 关于 / 调试模式) |

> 热键特意用 Ctrl 组合键:中文 IME 开启时,裸字母键会被输入法组合输入吃掉。

## 调试

设置环境变量 `POINTTOFIX_START_ACTIVE=1` 启动时直接进入标注模式(跳过点"开始标注")。
`POINTTOFIX_CLICKTEST=1` 在进入标注模式 10 帧后自动触发一次 ⊠ 去背(不依赖鼠标,便于自动化验证)。
`POINTTOFIX_GEOM_LOG=1` 把视口/窗口/工具条的真实几何打印到 stderr(排查多显示器贴合、DPI、工具条缩放问题)。
`POINTTOFIX_BAR_SCALE=0.8` 强制工具条缩放(调试"小屏装不下"的显示效果;不设则按屏幕高度自动决定)。

## 运行 / 打包

```bash
cargo run              # 开发运行(debug,保留控制台,可看 POINTTOFIX_* 调试输出)
cargo build --release  # 发布版:target/release/pointtofix.exe(约 16 MB)
```

**打包就是 `cargo build --release`**:主程序是**单文件 exe**(约 17 MB),直接拷走即可;
键控去背、标注、存图/复制/打印全都不依赖额外文件(libwebp 静态链入,字体运行时从
`C:\Windows\Fonts` 读取)。只有 **ISNet AI 去背**需要旁边放 `onnxruntime.dll` 和模型,
没有它们时「自动/键控」模式照常工作。release 版声明了
`windows_subsystem = "windows"`(见 `src/main.rs`),双击**不会弹控制台**;debug 构建仍保留控制台,
方便看 `POINTTOFIX_GEOM_LOG` 等日志。`Cargo.toml` 的 release profile 已开 `strip` 与 thin LTO。

依赖:Windows 10/11、Rust stable-msvc。首次编译需几分钟(WebP 编码走 `webp` crate 里的 libwebp,
编译期会用 MSVC 编译一份 C 源码;ONNX Runtime 走 `ort` 的 `load-dynamic`,构建时不下载二进制,
release + LTO 首次约 5 分钟)。
可选:本地 `.cargo/config.toml` 可配 rsproxy 镜像加速(该文件不随仓库分发,按需自建)。

ISNet 模型 + `onnxruntime.dll` 不随仓库分发,放到程序目录、`models\` 或
`%APPDATA%\pointtofix\models` 任意一处即可。推荐直接从魔搭下载现成的 fp16 版:

```bash
# 一次搞定:从魔搭下模型,并自动找/装 onnxruntime.dll,都放进 models\
python scripts/fetch_isnet.py                # fp16 (88 MB,推荐)
python scripts/fetch_isnet.py --variant int8 # int8 (44 MB,最小)
python scripts/fetch_isnet.py --variant fp32 # fp32 (176 MB,官方原版)
```

模型来源:
- [onnx-community/ISNet-ONNX](https://www.modelscope.cn/models/onnx-community/ISNet-ONNX)(魔搭,含 fp16 / fp32 / int8)
- [dragonsoar/imging-background-removal](https://www.modelscope.cn/models/dragonsoar/imging-background-removal)(魔搭,imgly CPU 量化版)
- rembg 官方 fp32:`isnet-general-use.onnx`(Apache-2.0,约 176 MB)

### 便携版目录

`build-portable.bat` 编译 release 后,直接把 exe、`onnxruntime.dll`、模型组装成
`dist\pointtofix-portable\`,并压成 `dist\pointtofix-portable.zip`:

```bat

目录内容:

```
dist\pointtofix-portable\
├── pointtofix.exe            # 主程序(约 17 MB)
├── onnxruntime.dll           # AI 去背推理库(约 19 MB)
├── isnet-general-use-fp16.onnx  # ISNet 模型(约 88 MB,来自 models\)

把整个目录拷到任何 Windows 10/11 x64 机器上双击即可运行,不需要安装、不需要 VC 运行库
(MSVC 静态链接)。`models\` 里没有 DLL / 模型时脚本会跳过它们,便携版就只剩键控去背。

## 架构(对应逆向结论)

原版 Pointofix 的核心就是"两个窗口 + 一个图形列表",本项目沿用该结构:

| 原版(逆向观察) | 本项目 |
| --- | --- |
| `TScreenForm` 全屏透明绘图层 | eframe 无边框置顶窗口,按物理像素铺满**当前显示器**;最底层是进入时冻结的显示器画面(不透明底图),墨迹画在 `Order::Background` 层 |
| `TToolForm` 竖排工具条 | 同一窗口内的 egui 浮动 Window(画布之上) |
| Delphi VCL GDI 绘图 | egui/epaint 矢量重绘,图形存 `Vec<Ink>`,撤销 = 弹栈 |
| 打印/保存屏幕内容 | `BitBlt(SRCCOPY | CAPTUREBLT)` 直接抓屏(分层窗口一起抓到,含墨迹) |

> **为什么标注层要铺冻结底图**:wgpu 的透明窗口在不少 AMD/NVIDIA 驱动和远程桌面会话里,
> 表面只报告 `Opaque`,透明清屏会被合成为纯黑——点「开始标注」后整屏发黑就是这个原因。
> 进入标注时先藏起待机面板、抓一张目标显示器画面铺在最底层,画面表现与原版一致(冻结当前屏幕),
> 同时彻底不依赖窗口透明。备用方案(改 glow/OpenGL)在不同驱动上同样不可靠,未采用。

代码结构:

```
src/
├── main.rs     # 入口:窗口属性(透明/无边框/置顶)+ 窗口图标
├── app.rs      # 状态机(Standby⇄Active)、冻结底图、工具条/设置 UI、输入处理、热键、导出(WebP/PNG 编码)
├── i18n.rs     # 界面文案国际化(中文 / English / Deutsch / 日本語 四套静态字符串表)
├── icons.rs    # 工具条矢量图标(epaint 绘制,不依赖字体符号)
├── ink.rs      # 墨迹模型(矢量图形 + epaint 重绘 + 撤销/重做栈)
├── capture.rs  # Win32 GDI 截屏(按显示器/区域,BGRA→RGBA;显示器枚举与定位)
├── bgremove.rs # 选区去背:键控算法 + 后台任务队列(键控/ISNet 自动回退)
├── isnet.rs    # ISNet ONNX 模型查找、ONNX Runtime 推理、遮罩后处理(matting off)
└── printing.rs # GDI 打印(默认打印机、等比适配页面居中)

assets/         # app.ico(多尺寸 PE 资源)+ pointtofixcraft.png(窗口图标)
models/         # (可选、不入库)onnxruntime.dll + ISNet 模型,AI 去背用
build.rs        # 用 embed-resource 把 app.ico 编进 exe
scripts/make_icon.py  # 图标生成脚本(Python + Pillow)
scripts/fetch_isnet.py # 从魔搭下载 ISNet 模型 + 准备 onnxruntime.dll
build-portable.bat    # release 编译 + 组装 dist\pointtofix-portable\(exe + DLL + 模型 + zip)
```

应用图标沿用 Pointofix 的四色圆盘 + 红色马克笔 + 鼠标指针,右下角加了 Rust 齿轮角标。
改图后运行 `python scripts/make_icon.py` 重新生成 `assets/`,再重新编译即可。

## 与原版对齐后的差距(下一步路线)

1. **存图不含工具条**:导出时"隐藏工具条两帧再抓屏"或"底图 + 墨迹矢量合成"替换现在的整屏 BitBlt
2. **点击穿透**:待机工具条支持 `MousePassthrough` 切换;标注层支持"临时穿透到下层窗口"
3. **全局热键**(系统级 Alt+S 开关,当前 Ctrl+R/M/I 仅标注模式内有效)与**托盘图标**(`tray-icon`)
4. 橡皮、原版的双列荧光/画笔配色
5. 多显示器:**已支持"单屏标注"**(按「开始标注」按钮所在显示器铺覆盖层,窗口=该屏物理矩形,
   各屏按自己的 DPI 渲染,存图/复制/打印只出这块屏)。要做**同时跨多屏标注**可再上
   "按虚拟屏铺开"或 winit 多 viewport,暂不需要
6. 设置持久化(原版是 INI;可用 `confy` 或注册表)
7. 白板/黑板模式(原版有,纯色背景)
8. 图标继续打磨(现已全部矢量绘制,保存=软盘、打印=打印机、撤销=↩、去背=魔棒、设置=齿轮;可换 SVG 资源获得更精细细节)

## 逆向笔记(Pointofix 1.8.0 观察)

- 3MB 单文件,Delphi/C++Builder VCL 原生程序,依赖仅系统 DLL,无网络、无壳、无 DRM
- 待机窗口 58×78(Start 按钮);激活后工具条 58×569 + 全屏 `TScreenForm`
- 隐藏对话框:设置、打印屏幕内容、区域选择、关于
- 二进制标记:Borland/CodeGear/Embarcadero、TForm/TApplication(即为 VCL,非 .NET)
